# Crockid Price Tracker

Учебный проект: анализ и сравнение цен на продукцию Crockid на Ozon и Wildberries.

## Стек
Python, pandas, SQLite, cron, Jupyter Notebook

## Структура
- `src/` — парсеры и скрипты
- `data/` — локальная база (не в репозитории)
- `notebooks/` — анализ данных

## Как запустить
1. Клонировать репозиторий
2. Создать venv и установить `pip install -r requirements.txt`
3. Запустить `python src/parse_wb.py`

## Статус
В процессе разработки.
