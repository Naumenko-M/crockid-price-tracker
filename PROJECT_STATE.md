# PROJECT_STATE.md — Crockid Price Tracker (Wildberries)

## 🎯 Идея проекта

Учебный проект для портфолио начинающего аналитика данных: **анализ цен на продукцию бренда Crockid на Wildberries**.

**Бизнес-вопрос:** как устроено ценообразование Crockid на WB? Есть ли разница цен по размерам и цветам, насколько честны скидки, как меняется цена во времени?

**Текущий фокус:** анализ размеров завершён (первые результаты), следующий шаг — анализ цветов.

## 🛠 Стек

- Python 3.13, pandas, sqlite3, matplotlib, seaborn, json
- `wb-private-api-python` (с `[browser]`, требует Chrome + Rosetta 2 на macOS)
- SQLite (`data/prices.db`), таблица `prices`
- **Ручной запуск парсера** (`run_parser.sh`), cron отложен. Возможно, позже — Airflow.
- VS Code + расширения: Python, Jupyter, SQLite (alexcvzz), Rainbow CSV
- Git + GitHub Desktop
- **Jupyter в VS Code иногда не запускает ядро** — обход: `.venv/bin/jupyter notebook` в браузере.

## 📊 Результаты анализа размеров (19.11.2026)

**Данные:**
- Всего товаров с размерами: **2597**
- Строк с размерами (развёрнутый `sizes_json`): **9286**

**Ключевые выводы:**
1. **Цена почти не зависит от размера.** На boxplot медианные цены для большинства размеров (68, 74, 80, 92, 104, 110, 116, 122, 128, 134, 140, 146) находятся в диапазоне ~1000–1500 руб. и визуально не различаются.
2. **Аномалия — размер «122-128».** Медиана ~4300 руб., разброс до 16000 руб. Вероятно, это товары другой категории (верхняя одежда), где размерная сетка указана диапазоном.
3. **Системное правило ценообразования.** У топ-10 товаров с максимальной разницей она составляет **ровно ~13%**. Это указывает на **фиксированный шаг за размер** (алгоритм WB или продавца), а не на рыночную стратегию.
4. **Пример топ-10** (min → max, diff_pct):
   - Брюки из флиса: 659 → 745 (13.05%)
   - Брюки флисовые: 829 → 937 (13.03%)
   - Флисовый комбинезон: 1666 → 1883 (13.03%)
   - Мембранное пальто: 4484 → 5068 (13.02%)
   - Свитшот: 1106 → 1250 (13.02%)
   - Школьные штаны: 1736 → 1962 (13.02%)
   - Платье: 1314 → 1485 (13.01%)
   - Зимнее пальто: 6158 → 6959 (13.01%)
   - Перчатки: 708 → 800 (12.99%)
   - Штаны со стрелками: 1578 → 1783 (12.99%)

**Черновик вывода для отчёта:**
> «Из 2597 товаров Crockid на WB часть имеет разную цену по размерам. Медианная разница — ~13%, максимальная — ~13%. Интересно, что у топ-10 товаров с максимальной разницей она составляет ровно ~13% — это указывает на системное правило ценообразования (фиксированный шаг за размер), а не на рыночную стратегию. Размер «122-128» выделяется высокой ценой — вероятно, это товары другой категории (верхняя одежда)».

**Что осталось посчитать (опционально):**
- Точная доля товаров с разными ценами по размерам (в %).
- Гистограмма распределения разницы (для визуализации).
- Пример конкретного товара: как меняется цена от размера к размеру (подтвердить «фиксированный шаг»).
